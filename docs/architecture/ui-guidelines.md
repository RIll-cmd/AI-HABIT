# UI & Design System Guidelines

## Color Palette
- **Background Main**: `#0B1020`
- **Surface Cards**: `#151C33`
- **Primary Accent (Blue)**: `#3B82F6`
- **Success Accent (Emerald)**: `#10B981`
- **Danger Accent (Red)**: `#EF4444`
- **Gold Accent**: `#F6C453`

## Radii Specifications
- **Surface Cards**: `20px` (`.saas-card`, `--radius-card`)
- **Action Buttons**: `16px` (`.saas-button`, `--radius-btn`)
- **Form Inputs**: `14px` (`.saas-input`, `--radius-input`)

## Elevation & Shadows
- **Small Shadow**: `0 2px 8px rgba(0, 0, 0, 0.25)` (`var(--shadow-sm)`)
- **Medium Shadow**: `0 4px 20px rgba(0, 0, 0, 0.40)` (`var(--shadow-md)`)
- **Large Shadow**: `0 10px 40px rgba(0, 0, 0, 0.60)` (`var(--shadow-lg)`)

## Typography Hierarchy
- **Headings**: `Space Grotesk` (`font-heading`)
- **Body & Text**: `Inter` (`font-sans`)
- **Numbers & Stats**: `JetBrains Mono` (`font-mono`)
